# WebDesign Studio Guide

1. **Create Site**: Enter a `siteKey` (e.g., `acme-dental`) and click **Create Site & Install Dependencies** to scaffold an Astro v7 project in `{workRoot}/sites/<siteKey>` with built-in SEO/GEO/cache primitives and Skills.
2. **Open with Agent**: Select an installed Agent (OpenCode / DSH) and click **Open with Agent**.
3. **Build, Wire & Ship in Chat**: Describe your design vision and materials directly in the Agent chat, iterate live, then ask the Agent to wire CMS/CRM, inject `seed/` data, and publish to Cloudflare.
