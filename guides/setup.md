# WebDesign 站点构建器使用指南

1. **新建站点**：输入英文站点标识（如 `acme-dental`），点击 **「创建站点并安装依赖」**，系统会自动在 `{workRoot}/sites/<siteKey>` 生成 Astro v7 基础工程、注入设计/SEO/GEO/CMS 规范并后台安装依赖。
2. **用 Agent 打开**：选择已安装的 Agent（如 OpenCode 或 DSH），点击 **「用 Agent 打开」**。
3. **对话完成一切**：
   - 在 Agent 对话框直接说出你的行业定位、设计风格、参考网址或产品资料，边聊边改静态站；
   - 满意后直接让 Agent 对接 CMS 集合、灌入 `seed/` 初始数据、挂载 CRM 并一键发布上线。
