# WebDesign Studio 使用指南

1. **打开工作台**：在 Deploy「运营 → 工具箱」启用 `WebDesign Studio`，点击 **「配置」** 即可在独立桌面窗口打开设计工作台。
2. **新建站点（阶段一：全静态）**：
   - 输入英文站点标识（如 `acme`）与一句话建站构想（色调、参考站、栏目、原始资料均为选填，信息越丰富生成越精准）。
   - 点击 **「保存并唤起 Agent 构建静态站」**，系统自动在 `{workRoot}/sites/<siteKey>` 初始化带 SEO/GEO 底座的 Astro 项目，并打开已安装的 DSH 或 OpenCode 开始构建。
3. **预览与体检**：在工作台内一键启动本地预览，运行 **SEO / GEO 合规体检**，不满意可随时补充修改意见再次派发给 Agent。
4. **对接后台（阶段二：CMS 集合与字段）**：
   - 静态效果满意后，切换到 **「CMS 数据对接」** 页签，检查集合与字段契约绿灯状态（请确保已在 Deploy 登录 CMS 且安装启用了 `cmsmcp`）。
   - 点击 **「唤起 Agent 完成前后台对接」**，Agent 将自动在 CMS 创建 `{siteKey}_*` 集合、灌入演示数据并将前端切换至真实公开接口（含询盘表单提交）。
5. **一键上线**：验证无误后，在 **「构建与上线」** 页签执行构建并直接发布至 Cloudflare Pages（自动配置自定义域名与 48h 边缘 HTML 缓存）。
